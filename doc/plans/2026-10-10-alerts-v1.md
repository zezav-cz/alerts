# alerts v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `alerts`, a Go daemon that runs monitoring-plugins style checks, turns results into alerts through a confirmation/recovery/reminder policy, and delivers them through routed notifiers (Telegram and exec), released as static linux/amd64 and linux/arm64 binaries.

**Architecture:** Three layers behind small interfaces — `check.Checker` produces a `Result`, the pure `policy.Evaluate` turns it into an optional `alert.Alert`, and `notify.Notifier`s deliver it, chosen by `notify.Route`. One core loop in `internal/daemon` owns all state, persists it to a JSON file, and drives per-notifier FIFO delivery queues with retry, a healthchecks.io heartbeat and the systemd watchdog.

**Tech Stack:** Go 1.26 (from nixpkgs), standard library plus `go.yaml.in/yaml/v3` (vendored); Nix flake with git-hooks.nix; just; GitHub Actions for CI and releases.

**Spec:** `doc/specs/2026-10-10-alerts-design.md` — read it before starting; this plan implements it task by task.

## Global Constraints

- Module path `github.com/zezav-cz/alerts`; `go 1.26` in `go.mod`.
- The only third-party module is `go.yaml.in/yaml/v3`, and it is vendored (`go mod vendor`, `vendor/` committed): `nix flake check` runs the Go hooks in a sandbox without network.
- Release binaries are built with `CGO_ENABLED=0 go build -trimpath -ldflags "-s -w -X main.version=vX.Y.Z"` for linux/amd64 and linux/arm64, named `alerts_linux_amd64` and `alerts_linux_arm64`, with `SHA256SUMS`.
- Defaults: `interval: 1m`, `retry_interval: 30s`, `timeout: 30s`, `confirm: 3`, `repeat: 6h`, notifier `timeout: 30s`, `heartbeat.every: 5m`, `heartbeat.fail_after: 15m`, `state_file: /var/lib/alerts/state.json`, config path `/etc/alerts/config.yaml`.
- Check and notifier names match `^[a-z0-9][a-z0-9_-]*$`.
- Commands run without a shell, with exactly `PATH=/usr/local/sbin:/usr/local/bin:/usr/sbin:/usr/bin:/sbin:/bin` and `LANG=C` plus any notifier `env`, in their own process group, killed as a group on timeout.
- Output lines: performance data (from the first `|`) removed, trimmed, cut to 500 characters.
- Delivery: backoff 10 s doubling to 10 min, at most 1 h even when a channel asks for more; undelivered alerts dropped after 24 h; shutdown grace 10 s; scheduling resolution 1 s; first runs spread over 10 s.
- Every commit: Conventional Commits subject ≤ 72 characters, `just ci` passing first, and the trailer `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`. No model names anywhere else in commits or files.
- Nix only sees files git knows: `git add` new files before `just lint` / `just ci`, or they are silently ignored.
- Markdown prose is not hard-wrapped: one paragraph or bullet per line.
- Test helper scripts in `testdata/` use `#!/bin/sh`, POSIX tools only, and must be `chmod +x` before `git add`.

## Review Focus

These are inputs the spec implies but does not spell out; each is pinned by a test in the task named.

1. **An empty or mistyped Hiera key renders a config with no checks** — expected: `alerts validate` rejects it, so Puppet never installs a config that silently monitors nothing. Test `no checks` in Task 5.
2. **The state directory is missing or read-only** — expected: the daemon refuses to start with a clear error instead of logging a save failure every second forever. `TestNewFailsWhenStateIsNotWritable` in Task 10.
3. **The wall clock steps back after a restart** (rpi01 has no RTC and boots on a stale clock) — expected: a persisted retry time far in the future does not stall delivery. `TestRetryFarInTheFutureMeansTheClockSteppedBack` in Task 10.
4. **An exec notifier that never reads stdin** (a webhook script with a fixed body, `/bin/true`) — expected: exit 0 counts as delivered, not as a broken-pipe failure. `TestExecNotifierMayIgnoreStdin` in Task 8.
5. **A plugin prints invalid UTF-8** — expected: the state file and the alert JSON stay valid. `TestInvalidUTF8OutputSurvives` in Task 7.

````markdown
## What this is

`alerts` is a small daemon that runs checks following the monitoring-plugins convention (one line of output, exit code 0/1/2/3 for OK/WARNING/CRITICAL/UNKNOWN) on a schedule, decides when a result is worth an alert — confirmed state changes, recoveries, reminders — and delivers it through pluggable notifiers, Telegram first. # Development
````

````markdown
## Setup

`direnv allow` once; the devshell then provides Go, golangci-lint, just and gh, and installs the git hooks (pre-commit, commit-msg with commitizen for Conventional Commits). Without direnv, prefix commands with `nix develop -c`.

## The gates

- `just test` runs `go test -race ./...`. The race detector needs a C toolchain, which is why the devshell is `mkShell` and not `mkShellNoCC`.
- `just lint` runs `nix flake check`, which runs every hook (gofmt, govet, staticcheck, golangci-lint, shellcheck, check-yaml, nixfmt, whitespace) in a sandbox over a copy of the tree. Nix only sees files git knows about: `git add` new files before `just lint`, or the check silently ignores them.
- `just ci` is both, and runs before every commit.

## Dependencies are vendored

The sandbox has no network, so Go modules cannot be downloaded there. The one third-party module (`go.yaml.in/yaml/v3`) lives in `vendor/`, which the hooks exclude. After changing `go.mod`:

```sh
go mod tidy
go mod vendor
git add go.mod go.sum vendor
```

Keep dependencies to the minimum; each one is code that ships in a monitoring daemon on every host.

## Tests

- Test helper scripts live in each package's `testdata/` and must be executable (`chmod +x`); git records the bit. They use `#!/bin/sh` and only POSIX tools, because they run with the minimal `PATH` that `internal/proc` gives every command.
- `internal/policy` is pure: test it with tables of results and times, never with sleeps.
- `internal/daemon` tests drive the core loop by hand: the harness in `daemon_test.go` owns the clock and consumes the result and outcome channels itself, so a whole scenario — problem, reminder, failed delivery, restart — runs deterministically in milliseconds. Use it for any new daemon behaviour.
- `internal/notify` tests talk to `httptest` servers; nothing in the suite reaches the internet.
````

```go
// Package check runs checks that follow the monitoring-plugins convention:
// one line of output and an exit code of 0, 1, 2 or 3.
package check

import "fmt"

// State is a check's outcome, numbered like the plugin exit codes.
type State int

// The four plugin states, in exit-code order.
const (
	OK State = iota
	Warning
	Critical
	Unknown
)

var stateNames = [...]string{"OK", "WARNING", "CRITICAL", "UNKNOWN"}

// String returns the upper-case name, or State(n) for a value out of range.
func (s State) String() string {
	if s >= OK && s <= Unknown {
		return stateNames[s]
	}
	return fmt.Sprintf("State(%d)", int(s))
}

// ParseState is the inverse of String for the four valid states.
func ParseState(name string) (State, error) {
	for i, n := range stateNames {
		if n == name {
			return State(i), nil
		}
	}
	return 0, fmt.Errorf("unknown state %q (want OK, WARNING, CRITICAL or UNKNOWN)", name)
}

// MarshalText encodes the state by name, so JSON carries "CRITICAL", not 2.
func (s State) MarshalText() ([]byte, error) {
	if s < OK || s > Unknown {
		return nil, fmt.Errorf("invalid state %d", int(s))
	}
	return []byte(s.String()), nil
}

// UnmarshalText decodes a state name.
func (s *State) UnmarshalText(b []byte) error {
	v, err := ParseState(string(b))
	if err != nil {
		return err
	}
	*s = v
	return nil
}
```

```go
	"io/fs"
	"os/exec"
	"slices"
	"strings"
	"syscall"
	"time"
)

// BaseEnv is the environment every command starts from.
var BaseEnv = []string{
	"PATH=/usr/local/sbin:/usr/local/bin:/usr/sbin:/usr/bin:/sbin:/bin",
	"LANG=C",
}

// Output is what a finished command left behind.
type Output struct {
	Stdout   []byte
	Stderr   []byte
	TimedOut bool
}

// Run executes argv with BaseEnv plus env, feeding stdin when it is not nil.
// The error is exec's: nil, an *exec.ExitError, or a failure to start. When
// timeout expires the process group is killed and Output.TimedOut is set.
func Run(ctx context.Context, argv []string, env []string, stdin []byte, timeout time.Duration) (Output, error) {
	if len(argv) == 0 {
		return Output{}, errors.New("empty command")
	}
	ctx, cancel := context.WithTimeout(ctx, timeout)
	defer cancel()

	var stdout, stderr bytes.Buffer
	cmd := exec.CommandContext(ctx, argv[0], argv[1:]...)
	cmd.Env = append(slices.Clone(BaseEnv), env...)
	cmd.Stdout = &stdout
	cmd.Stderr = &stderr
	if stdin != nil {
		cmd.Stdin = bytes.NewReader(stdin)
	}
	// A process group of its own, so the kill also reaches anything forked.
	cmd.SysProcAttr = &syscall.SysProcAttr{Setpgid: true}
	cmd.Cancel = func() error { return syscall.Kill(-cmd.Process.Pid, syscall.SIGKILL) }
	// Stop waiting for pipes held open by a child that escaped the group.
	cmd.WaitDelay = 2 * time.Second

	err := cmd.Run()
	return Output{
		Stdout:   stdout.Bytes(),
		Stderr:   stderr.Bytes(),
		TimedOut: err != nil && errors.Is(ctx.Err(), context.DeadlineExceeded),
	}, err
}

// FirstLine returns the first non-blank line of b, trimmed.
func FirstLine(b []byte) string {
	for line := range strings.Lines(string(b)) {
		if s := strings.TrimSpace(line); s != "" {
			return s
		}
	}
	return ""
}

// Reason turns an error from Run into a short cause without exec's
// wrapping: "exit status 4", "signal: killed", "no such file or directory".
func Reason(err error) string {
	var exitErr *exec.ExitError
	if errors.As(err, &exitErr) {
		return exitErr.Error()
	}
	var pathErr *fs.PathError
	if errors.As(err, &pathErr) {
		return pathErr.Err.Error()
	}
	var execErr *exec.Error
	if errors.As(err, &execErr) {
		return execErr.Err.Error()
	}
	return err.Error()
}
```

```go
package check

import (
	"context"
	"errors"
	"fmt"
	"os/exec"
	"strings"
	"time"
	"unicode/utf8"

	"github.com/zezav-cz/alerts/internal/proc"
)

// Result is one run of a check.
type Result struct {
	State    State
	Output   string
	Duration time.Duration
}

// Checker runs a check once. Every problem, including the check being unable
// to run at all, is reported as a Result rather than an error.
type Checker interface {
	Check(ctx context.Context) Result
}

// maxOutput caps the output line, in characters.
const maxOutput = 500

// Exec runs a command following the plugin convention: the exit code is the
// state and the first line of output is the message.
type Exec struct {
	Command []string
	Timeout time.Duration
}

// Check runs the command once.
func (e Exec) Check(ctx context.Context) Result {
	if len(e.Command) == 0 {
		return Result{State: Unknown, Output: "empty command"}
	}
	start := time.Now()
	out, err := proc.Run(ctx, e.Command, nil, nil, e.Timeout)
	res := Result{Duration: time.Since(start)}

	line := clean(proc.FirstLine(out.Stdout))
	if line == "" {
		line = clean(proc.FirstLine(out.Stderr))
	}

	var exitErr *exec.ExitError
	switch {
	case out.TimedOut:
		res.State, res.Output = Unknown, fmt.Sprintf("timed out after %s", e.Timeout)
	case err == nil:
		res.State, res.Output = OK, line
	case errors.As(err, &exitErr) && exitErr.ExitCode() >= 1 && exitErr.ExitCode() <= 3:
		res.State, res.Output = State(exitErr.ExitCode()), line
	case errors.As(err, &exitErr):
		res.State, res.Output = Unknown, proc.Reason(err)
		if line != "" {
			res.Output += ": " + line
		}
	default:
		res.State, res.Output = Unknown, fmt.Sprintf("cannot run %s: %s", e.Command[0], proc.Reason(err))
	}
	if res.Output == "" {
		res.Output = "(no output)"
	}
	return res
}

// clean drops performance data (everything from the first "|"), trims, and
// caps the line at maxOutput characters.
func clean(line string) string {
	if i := strings.IndexByte(line, '|'); i >= 0 {
		line = line[:i]
	}
	line = strings.TrimSpace(line)
	if utf8.RuneCountInString(line) > maxOutput {
		line = string([]rune(line)[:maxOutput])
	}
	return line
}
```

```go
// Package alert defines the event alerts delivers and its human-readable
// text.
package alert

import (
	"fmt"
	"time"

	"github.com/zezav-cz/alerts/internal/check"
)

// Kind says why an alert was emitted.
type Kind string

// The alert kinds.
const (
	Problem  Kind = "problem"
	Recovery Kind = "recovery"
	Reminder Kind = "reminder"
	Test     Kind = "test"
)

// Alert is what notifiers deliver. Its JSON form is the stdin contract of
// exec notifiers.
type Alert struct {
	Kind          Kind        `json:"kind"`
	Host          string      `json:"host"`
	Check         string      `json:"check"`
	State         check.State `json:"state"`
	PreviousState check.State `json:"previous_state"`
	Output        string      `json:"output"`
	Since         time.Time   `json:"since"`
	Time          time.Time   `json:"time"`
	Text          string      `json:"text"`
}

// RouteState is the state an alert is routed by: the state recovered from
// for a recovery, so the "OK again" reaches whoever got the problem, and the
// alert's own state otherwise.
func (a Alert) RouteState() check.State {
	if a.Kind == Recovery {
		return a.PreviousState
	}
	return a.State
}

// NewProblem is a confirmed change into a non-OK state.
func NewProblem(host, name string, from, to check.State, output string, now time.Time) Alert {
	return Alert{
		Kind: Problem, Host: host, Check: name, State: to, PreviousState: from,
		Output: output, Since: now, Time: now,
		Text: fmt.Sprintf("%s %s %s %s\n%s", icon(to), host, name, to, output),
	}
}

// NewRecovery is a confirmed return to OK from a state entered at fromSince.
func NewRecovery(host, name string, from check.State, fromSince time.Time, output string, now time.Time) Alert {
	return Alert{
		Kind: Recovery, Host: host, Check: name, State: check.OK, PreviousState: from,
		Output: output, Since: now, Time: now,
		Text: fmt.Sprintf("✅ %s %s OK (was %s for %s)\n%s", host, name, from, Duration(now.Sub(fromSince)), output),
	}
}

// NewReminder repeats a problem that is still there.
func NewReminder(host, name string, state check.State, since time.Time, output string, now time.Time) Alert {
	return Alert{
		Kind: Reminder, Host: host, Check: name, State: state, PreviousState: state,
		Output: output, Since: since, Time: now,
		Text: fmt.Sprintf("🔁 %s %s still %s (for %s)\n%s", host, name, state, Duration(now.Sub(since)), output),
	}
}

// NewTest is the alert `alerts test-notify` sends.
func NewTest(host, version, notifier string, now time.Time) Alert {
	return Alert{
		Kind: Test, Host: host, Check: "test", State: check.OK, PreviousState: check.OK,
		Output: "test alert", Since: now, Time: now,
		Text: fmt.Sprintf("🧪 %s test alert from alerts %s via %s", host, version, notifier),
	}
}

func icon(s check.State) string {
	switch s {
	case check.Critical:
		return "🔴"
	case check.Warning:
		return "🟡"
	case check.Unknown:
		return "⚪"
	default:
		return "✅"
	}
}

// Duration formats d rounded to the minute, with zero parts left out: 2h13m,
// 6h, 45m. Anything that rounds to under a minute is "<1m".
func Duration(d time.Duration) string {
	d = d.Round(time.Minute)
	if d < time.Minute {
		return "<1m"
	}
	h, m := d/time.Hour, (d%time.Hour)/time.Minute
	switch {
	case h == 0:
		return fmt.Sprintf("%dm", m)
	case m == 0:
		return fmt.Sprintf("%dh", h)
	default:
		return fmt.Sprintf("%dh%dm", h, m)
	}
}
```

```go
// Package config loads and validates the alerts YAML configuration.
package config

import (
	"bytes"
	"errors"
	"fmt"
	"io"
	"os"
	"slices"
	"strings"
	"time"

	"go.yaml.in/yaml/v3"

	"github.com/zezav-cz/alerts/internal/check"
)

// Paths used when nothing else is given.
const (
	DefaultPath      = "/etc/alerts/config.yaml"
	DefaultStateFile = "/var/lib/alerts/state.json"
)

// Config is a validated configuration with every default filled in.
type Config struct {
	Host      string
	StateFile string
	Heartbeat *Heartbeat // nil when not configured
	Notifiers []Notifier
	Routes    []Route
	Checks    []Check
}

// Heartbeat is the dead man's switch ping.
type Heartbeat struct {
	URLFile   string
	Every     time.Duration
	FailAfter time.Duration
}

// Notifier is one delivery channel. TokenFile and ChatID apply to telegram,
// Command and Env to exec; Timeout to both.
type Notifier struct {
	Name      string
	Type      string
	TokenFile string
	ChatID    string
	Command   []string
	Env       map[string]string
	Timeout   time.Duration
}

// Route sends alerts matching all of its non-empty matchers to Notify.
type Route struct {
	States []check.State
	Checks []string
	Notify []string
}

// Matches reports whether the route applies to an alert for check name,
// routed by state s.
func (r Route) Matches(name string, s check.State) bool {
	return (len(r.States) == 0 || slices.Contains(r.States, s)) &&
		(len(r.Checks) == 0 || slices.Contains(r.Checks, name))
}

// Check is one scheduled check with its effective settings.
type Check struct {
	Name          string
	Type          string
	Command       []string
	Interval      time.Duration
	RetryInterval time.Duration
	Timeout       time.Duration
	Confirm       int
	Repeat        time.Duration
}

// Load reads and validates the file at path. An empty host defaults to the
// machine's short hostname.
func Load(path string) (*Config, error) {
	data, err := os.ReadFile(path)
	if err != nil {
		return nil, err
	}
	cfg, err := Parse(data)
	if err != nil {
		return nil, fmt.Errorf("%s:\n%w", path, err)
	}
	if cfg.Host == "" {
		h, err := os.Hostname()
		if err != nil {
			return nil, fmt.Errorf("host is not set and the hostname is unavailable: %w", err)
		}
		cfg.Host, _, _ = strings.Cut(h, ".")
	}
	return cfg, nil
}

// Parse decodes and validates a configuration document. Unknown keys are
// errors. Validation problems are all reported together, one per line.
func Parse(data []byte) (*Config, error) {
	var raw rawConfig
	dec := yaml.NewDecoder(bytes.NewReader(data))
	dec.KnownFields(true)
	if err := dec.Decode(&raw); err != nil {
		if errors.Is(err, io.EOF) {
			return nil, errors.New("config is empty")
		}
		return nil, err
	}
	v := &validator{}
	cfg := v.build(&raw)
	if err := errors.Join(v.errs...); err != nil {
		return nil, err
	}
	return cfg, nil
}
```

```go
package config

import (
	"fmt"
	"regexp"
	"slices"
	"time"

	"github.com/zezav-cz/alerts/internal/check"
)

// The YAML shape. Optional settings are pointers so "absent" and "zero" differ.
type rawConfig struct {
	Host      string        `yaml:"host"`
	StateFile string        `yaml:"state_file"`
	Defaults  rawSettings   `yaml:"defaults"`
	Heartbeat *rawHeartbeat `yaml:"heartbeat"`
	Notifiers []rawNotifier `yaml:"notifiers"`
	Routes    []rawRoute    `yaml:"routes"`
	Checks    []rawCheck    `yaml:"checks"`
}

type rawSettings struct {
	Interval      *string `yaml:"interval"`
	RetryInterval *string `yaml:"retry_interval"`
	Timeout       *string `yaml:"timeout"`
	Confirm       *int    `yaml:"confirm"`
	Repeat        *string `yaml:"repeat"`
}

type rawHeartbeat struct {
	URLFile   string  `yaml:"url_file"`
	Every     *string `yaml:"every"`
	FailAfter *string `yaml:"fail_after"`
}

type rawNotifier struct {
	Name      string            `yaml:"name"`
	Type      string            `yaml:"type"`
	TokenFile string            `yaml:"token_file"`
	ChatID    any               `yaml:"chat_id"` // any, to tell a quoted string from a number
	Command   []string          `yaml:"command"`
	Env       map[string]string `yaml:"env"`
	Timeout   *string           `yaml:"timeout"`
}

type rawRoute struct {
	States []string `yaml:"states"`
	Checks []string `yaml:"checks"`
	Notify []string `yaml:"notify"`
}

type rawCheck struct {
	Name        string   `yaml:"name"`
	Type        string   `yaml:"type"`
	Command     []string `yaml:"command"`
	rawSettings `yaml:",inline"`
}

// settings are the per-check knobs that `defaults` provides.
type settings struct {
	Interval, RetryInterval, Timeout, Repeat time.Duration
	Confirm                                  int
}

var builtinDefaults = settings{
	Interval:      time.Minute,
	RetryInterval: 30 * time.Second,
	Timeout:       30 * time.Second,
	Confirm:       3,
	Repeat:        6 * time.Hour,
}

var namePattern = regexp.MustCompile(`^[a-z0-9][a-z0-9_-]*$`)

// problemStates are the states an alert can be routed by.
var problemStates = []check.State{check.Warning, check.Critical, check.Unknown}

type validator struct{ errs []error }

func (v *validator) addf(format string, args ...any) {
	v.errs = append(v.errs, fmt.Errorf(format, args...))
}

func (v *validator) build(raw *rawConfig) *Config {
	cfg := &Config{Host: raw.Host, StateFile: raw.StateFile}
	if cfg.StateFile == "" {
		cfg.StateFile = DefaultStateFile
	}
	base := v.settings("defaults", raw.Defaults, builtinDefaults)

	if h := raw.Heartbeat; h != nil {
		if h.URLFile == "" {
			v.addf("heartbeat.url_file: required")
		}
		cfg.Heartbeat = &Heartbeat{
			URLFile:   h.URLFile,
			Every:     v.duration("heartbeat.every", h.Every, 5*time.Minute, false),
			FailAfter: v.duration("heartbeat.fail_after", h.FailAfter, 15*time.Minute, false),
		}
	}

	notifierNames := map[string]bool{}
	for i, rn := range raw.Notifiers {
		where := v.name(fmt.Sprintf("notifiers[%d]", i), rn.Name, notifierNames)
		cfg.Notifiers = append(cfg.Notifiers, v.notifier(where, rn))
	}

	checkNames := map[string]bool{}
	for i, rc := range raw.Checks {
		where := v.name(fmt.Sprintf("checks[%d]", i), rc.Name, checkNames)
		c := Check{Name: rc.Name, Type: rc.Type, Command: rc.Command}
		if c.Type == "" {
			c.Type = "exec"
		} else if c.Type != "exec" {
			v.addf("%s.type: unknown type %q (only exec in this version)", where, c.Type)
		}
		if len(c.Command) == 0 {
			v.addf("%s.command: required", where)
		}
		s := v.settings(where, rc.rawSettings, base)
		c.Interval, c.RetryInterval, c.Timeout, c.Confirm, c.Repeat = s.Interval, s.RetryInterval, s.Timeout, s.Confirm, s.Repeat
		cfg.Checks = append(cfg.Checks, c)
	}

	if len(raw.Checks) == 0 {
		v.addf("checks: at least one check is required")
	}

	for i, rr := range raw.Routes {
		cfg.Routes = append(cfg.Routes, v.route(fmt.Sprintf("routes[%d]", i), rr, checkNames, notifierNames))
	}

	for _, c := range cfg.Checks {
		for _, s := range problemStates {
			if !slices.ContainsFunc(cfg.Routes, func(r Route) bool { return r.Matches(c.Name, s) }) {
				v.addf("check %s: a %s alert would match no route", c.Name, s)
			}
		}
	}
	return cfg
}

// name validates a check or notifier name and returns the location prefix
// for further messages about the same entry.
func (v *validator) name(where, name string, seen map[string]bool) string {
	switch {
	case name == "":
		v.addf("%s.name: required", where)
		return where
	case !namePattern.MatchString(name):
		v.addf("%s.name: %q must match %s", where, name, namePattern)
	case seen[name]:
		v.addf("%s.name: duplicate %q", where, name)
	}
	seen[name] = true
	return fmt.Sprintf("%s (%s)", where, name)
}

func (v *validator) notifier(where string, rn rawNotifier) Notifier {
	n := Notifier{
		Name: rn.Name, Type: rn.Type, TokenFile: rn.TokenFile, Command: rn.Command, Env: rn.Env,
		Timeout: v.duration(where+".timeout", rn.Timeout, 30*time.Second, false),
	}
	switch rn.Type {
	case "telegram":
		if rn.TokenFile == "" {
			v.addf("%s.token_file: required for telegram", where)
		}
		switch id := rn.ChatID.(type) {
		case nil:
			v.addf("%s.chat_id: required for telegram", where)
		case string:
			if id == "" {
				v.addf("%s.chat_id: required for telegram", where)
			}
			n.ChatID = id
		default:
			v.addf(`%s.chat_id: must be a quoted string, e.g. chat_id: "%v"`, where, id)
		}
		if len(rn.Command) > 0 || len(rn.Env) > 0 {
			v.addf("%s: command and env apply to exec notifiers only", where)
		}
	case "exec":
		if len(rn.Command) == 0 {
			v.addf("%s.command: required for exec", where)
		}
		if rn.TokenFile != "" || rn.ChatID != nil {
			v.addf("%s: token_file and chat_id apply to telegram notifiers only", where)
		}
	case "":
		v.addf("%s.type: required (telegram or exec)", where)
	default:
		v.addf("%s.type: unknown type %q (want telegram or exec)", where, rn.Type)
	}
	return n
}

func (v *validator) route(where string, rr rawRoute, checks, notifiers map[string]bool) Route {
	r := Route{Checks: rr.Checks, Notify: rr.Notify}
	for _, name := range rr.States {
		s, err := check.ParseState(name)
		switch {
		case err != nil:
			v.addf("%s.states: %v", where, err)
		case s == check.OK:
			v.addf("%s.states: OK cannot be routed; a recovery follows the state it recovered from", where)
		default:
			r.States = append(r.States, s)
		}
	}
	for _, c := range rr.Checks {
		if !checks[c] {
			v.addf("%s.checks: unknown check %q", where, c)
		}
	}
	if len(rr.Notify) == 0 {
		v.addf("%s.notify: required", where)
	}
	for _, n := range rr.Notify {
		if !notifiers[n] {
			v.addf("%s.notify: unknown notifier %q", where, n)
		}
	}
	return r
}

func (v *validator) settings(where string, r rawSettings, base settings) settings {
	s := settings{
		Interval:      v.duration(where+".interval", r.Interval, base.Interval, false),
		RetryInterval: v.duration(where+".retry_interval", r.RetryInterval, base.RetryInterval, false),
		Timeout:       v.duration(where+".timeout", r.Timeout, base.Timeout, false),
		Repeat:        v.duration(where+".repeat", r.Repeat, base.Repeat, true),
		Confirm:       base.Confirm,
	}
	if r.Confirm != nil {
		if *r.Confirm < 1 {
			v.addf("%s.confirm: must be at least 1, got %d", where, *r.Confirm)
		} else {
			s.Confirm = *r.Confirm
		}
	}
	return s
}

// duration parses an optional duration, falling back to def when absent.
func (v *validator) duration(where string, s *string, def time.Duration, allowZero bool) time.Duration {
	if s == nil {
		return def
	}
	d, err := time.ParseDuration(*s)
	switch {
	case err != nil:
		v.addf("%s: %q is not a duration like 30s, 5m or 6h", where, *s)
	case d < 0 || (d == 0 && !allowZero):
		v.addf("%s: must be positive, got %s", where, *s)
	default:
		return d
	}
	return def
}
```

```go
// Package policy decides when a check result becomes an alert. It is a pure
// function of its inputs: no I/O and no clock of its own.
package policy

import (
	"time"

	"github.com/zezav-cz/alerts/internal/alert"
	"github.com/zezav-cz/alerts/internal/check"
)

// Settings are the per-check knobs the policy needs.
type Settings struct {
	Confirm int           // consecutive differing results before the state changes
	Repeat  time.Duration // reminder period while not OK; 0 disables reminders
}

// CheckState is what the policy remembers about one check between results.
type CheckState struct {
	Confirmed    check.State `json:"confirmed"`
	Since        time.Time   `json:"since"`
	Pending      int         `json:"pending"`
	PendingState check.State `json:"pending_state"`
	LastOutput   string      `json:"last_output"`
	LastAlert    time.Time   `json:"last_alert,omitzero"`
}

// Initial is the state of a check never seen before: OK since now, so a
// healthy check sends nothing and an existing problem alerts once confirmed.
func Initial(now time.Time) CheckState {
	return CheckState{Confirmed: check.OK, Since: now, PendingState: check.OK}
}

// Evaluate applies one result and returns the new state plus the alert to
// send, if any. At most one alert comes out of one result.
func Evaluate(host, name string, prev CheckState, r check.Result, now time.Time, s Settings) (CheckState, *alert.Alert) {
	next := prev
	next.LastOutput = r.Output

	if r.State == prev.Confirmed {
		next.Pending, next.PendingState = 0, prev.Confirmed
		if next.Confirmed != check.OK && s.Repeat > 0 && now.Sub(next.LastAlert) >= s.Repeat {
			a := alert.NewReminder(host, name, next.Confirmed, next.Since, r.Output, now)
			next.LastAlert = now
			return next, &a
		}
		return next, nil
	}

	next.Pending++
	next.PendingState = r.State
	if next.Pending < s.Confirm {
		return next, nil
	}

	var a alert.Alert
	if r.State == check.OK {
		a = alert.NewRecovery(host, name, prev.Confirmed, prev.Since, r.Output, now)
	} else {
		a = alert.NewProblem(host, name, prev.Confirmed, r.State, r.Output, now)
	}
	next.Confirmed, next.Since = r.State, now
	next.Pending, next.PendingState = 0, r.State
	next.LastAlert = now
	return next, &a
}
```

```go
// Package state persists what the daemon must not forget across restarts:
// each check's policy state and every notifier's undelivered alerts.
package state

import (
	"encoding/json"
	"errors"
	"fmt"
	"io/fs"
	"os"
	"path/filepath"
	"time"

	"github.com/zezav-cz/alerts/internal/alert"
	"github.com/zezav-cz/alerts/internal/policy"
)

// Version is the state file format this build reads and writes.
const Version = 1

// Queued is an alert waiting for one notifier.
type Queued struct {
	Alert    alert.Alert `json:"alert"`
	Enqueued time.Time   `json:"enqueued"`
	Attempts int         `json:"attempts"`
	NextTry  time.Time   `json:"next_try"`
}

// State is the whole persisted state.
type State struct {
	Version int                          `json:"version"`
	Checks  map[string]policy.CheckState `json:"checks"`
	Queues  map[string][]Queued          `json:"queues"`
}

// New returns an empty state.
func New() *State {
	return &State{Version: Version, Checks: map[string]policy.CheckState{}, Queues: map[string][]Queued{}}
}

// Read parses the state file without side effects. A missing file is an
// empty state, not an error.
func Read(path string) (*State, error) {
	data, err := os.ReadFile(path)
	if errors.Is(err, fs.ErrNotExist) {
		return New(), nil
	}
	if err != nil {
		return nil, err
	}
	s := New()
	if err := json.Unmarshal(data, s); err != nil {
		return nil, fmt.Errorf("parse %s: %w", path, err)
	}
	if s.Version != Version {
		return nil, fmt.Errorf("%s: unsupported state version %d", path, s.Version)
	}
	if s.Checks == nil {
		s.Checks = map[string]policy.CheckState{}
	}
	if s.Queues == nil {
		s.Queues = map[string][]Queued{}
	}
	return s, nil
}

// Load is Read for the daemon. A state file that cannot be used is moved
// aside to path+".corrupt" and replaced by an empty state: the worst case is
// a repeated alert, never silence. The returned state is never nil; a non-nil
// error says what was discarded and should be logged.
func Load(path string) (*State, error) {
	s, err := Read(path)
	if err == nil {
		return s, nil
	}
	if rerr := os.Rename(path, path+".corrupt"); rerr != nil {
		err = fmt.Errorf("%w (moving it aside failed too: %v)", err, rerr)
	}
	return New(), fmt.Errorf("starting with empty state: %w", err)
}

// Save writes s atomically: a temporary file in the same directory, fsynced,
// then renamed over path. An interrupted Save leaves the old file intact.
func Save(path string, s *State) error {
	data, err := json.MarshalIndent(s, "", "  ")
	if err != nil {
		return err
	}
	tmp, err := os.CreateTemp(filepath.Dir(path), ".state-*.tmp")
	if err != nil {
		return err
	}
	defer os.Remove(tmp.Name()) // a no-op once the rename succeeded
	if _, err := tmp.Write(append(data, '\n')); err != nil {
		tmp.Close()
		return err
	}
	if err := tmp.Sync(); err != nil {
		tmp.Close()
		return err
	}
	if err := tmp.Close(); err != nil {
		return err
	}
	return os.Rename(tmp.Name(), path)
}
```

```go
// Package notify delivers alerts through pluggable channels.
package notify

import (
	"context"
	"errors"
	"fmt"
	"net/http"
	"os"
	"slices"
	"strings"
	"time"

	"github.com/zezav-cz/alerts/internal/alert"
	"github.com/zezav-cz/alerts/internal/config"
)

// Notifier delivers one alert. A nil error means delivered; any error is
// retried by the caller.
type Notifier interface {
	Name() string
	Send(ctx context.Context, a alert.Alert) error
}

// RetryAfterError is a failure that names the earliest sensible retry.
type RetryAfterError struct {
	After time.Duration
	Err   error
}

func (e *RetryAfterError) Error() string { return e.Err.Error() }
func (e *RetryAfterError) Unwrap() error { return e.Err }

// RetryAfter returns the wait a failure asks for, or 0 if it names none.
func RetryAfter(err error) time.Duration {
	var r *RetryAfterError
	if errors.As(err, &r) {
		return r.After
	}
	return 0
}

// Build constructs the notifier a config entry describes. For telegram it
// reads the token file, so a missing or empty token fails here, at start-up.
func Build(c config.Notifier, client *http.Client) (Notifier, error) {
	switch c.Type {
	case "telegram":
		b, err := os.ReadFile(c.TokenFile)
		if err != nil {
			return nil, fmt.Errorf("notifier %s: %w", c.Name, err)
		}
		token := strings.TrimSpace(string(b))
		if token == "" {
			return nil, fmt.Errorf("notifier %s: %s is empty", c.Name, c.TokenFile)
		}
		return NewTelegram(c.Name, token, c.ChatID, client), nil
	case "exec":
		return NewExec(c.Name, c.Command, c.Env, c.Timeout), nil
	}
	return nil, fmt.Errorf("notifier %s: unknown type %q", c.Name, c.Type)
}

// Route returns the notifiers an alert goes to: the union of every matching
// route, in order of first appearance.
func Route(routes []config.Route, a alert.Alert) []string {
	var names []string
	s := a.RouteState()
	for _, r := range routes {
		if !r.Matches(a.Check, s) {
			continue
		}
		for _, n := range r.Notify {
			if !slices.Contains(names, n) {
				names = append(names, n)
			}
		}
	}
	return names
}
```

```go
	"github.com/zezav-cz/alerts/internal/alert"

// Telegram sends the alert's text as a plain message through the Bot API.
// No parse_mode is set, so the text needs no escaping.
type Telegram struct {
	name    string
	token   string
	chatID  string
	client  *http.Client
	baseURL string
}

// NewTelegram returns a Telegram notifier posting to api.telegram.org.
func NewTelegram(name, token, chatID string, client *http.Client) *Telegram {
	return &Telegram{name: name, token: token, chatID: chatID, client: client, baseURL: "https://api.telegram.org"}
}

// Name returns the notifier's configured name.
func (t *Telegram) Name() string { return t.name }

// Send posts one message.
func (t *Telegram) Send(ctx context.Context, a alert.Alert) error {
	body, err := json.Marshal(map[string]any{
		"chat_id":              t.chatID,
		"text":                 a.Text,
		"link_preview_options": map[string]bool{"is_disabled": true},
	})
	if err != nil {
		return err
	}
	req, err := http.NewRequestWithContext(ctx, http.MethodPost, t.baseURL+"/bot"+t.token+"/sendMessage", bytes.NewReader(body))
	if err != nil {
		return t.redact(err)
	}
	req.Header.Set("Content-Type", "application/json")
	resp, err := t.client.Do(req)
	if err != nil {
		return t.redact(err)
	}
	defer resp.Body.Close()

	var reply struct {
		OK          bool   `json:"ok"`
		Description string `json:"description"`
		Parameters  struct {
			RetryAfter int `json:"retry_after"`
		} `json:"parameters"`
	}
	_ = json.NewDecoder(io.LimitReader(resp.Body, 1<<20)).Decode(&reply)

	switch {
	case resp.StatusCode == http.StatusTooManyRequests:
		return &RetryAfterError{
			After: time.Duration(reply.Parameters.RetryAfter) * time.Second,
			Err:   fmt.Errorf("telegram: HTTP 429: %s", reply.Description),
		}
	case resp.StatusCode/100 != 2:
		return fmt.Errorf("telegram: HTTP %d: %s", resp.StatusCode, reply.Description)
	case !reply.OK:
		return fmt.Errorf("telegram: request not ok: %s", reply.Description)
	}
	return nil
}

// redact strips the bot token, which net/http errors carry inside the URL.
func (t *Telegram) redact(err error) error {
	return errors.New(strings.ReplaceAll(err.Error(), t.token, "<token>"))
}
```

```go
import (
	"context"
	"encoding/json"
	"errors"
	"fmt"
	"maps"
	"slices"
	"time"

	"github.com/zezav-cz/alerts/internal/alert"
	"github.com/zezav-cz/alerts/internal/proc"
)

// Exec hands the alert as JSON on stdin to a command. Exit 0 is delivered.
type Exec struct {
	name    string
	command []string
	env     map[string]string
	timeout time.Duration
}

// NewExec returns an exec notifier.
func NewExec(name string, command []string, env map[string]string, timeout time.Duration) *Exec {
	return &Exec{name: name, command: command, env: env, timeout: timeout}
}

// Name returns the notifier's configured name.
func (e *Exec) Name() string { return e.name }

// Send runs the command once with the alert on stdin.
func (e *Exec) Send(ctx context.Context, a alert.Alert) error {
	if len(e.command) == 0 {
		return errors.New("empty command")
	}
	payload, err := json.Marshal(a)
	if err != nil {
		return err
	}
	env := make([]string, 0, len(e.env))
	for _, k := range slices.Sorted(maps.Keys(e.env)) {
		env = append(env, k+"="+e.env[k])
	}
	out, err := proc.Run(ctx, e.command, env, payload, e.timeout)
	switch {
	case out.TimedOut:
		return fmt.Errorf("%s: timed out after %s", e.command[0], e.timeout)
	case err != nil:
		msg := fmt.Sprintf("%s: %s", e.command[0], proc.Reason(err))
		if line := proc.FirstLine(out.Stderr); line != "" {
			msg += ": " + line
		}
		return errors.New(msg)
	}
	return nil
}
```

```go
// Package sdnotify speaks systemd's notify protocol (READY=1, WATCHDOG=1,
// STOPPING=1) without a library.
package sdnotify

import (
	"net"
	"os"
	"strconv"
	"strings"
	"time"
)

// Send writes state to $NOTIFY_SOCKET. Without that variable, i.e. when not
// run by systemd with Type=notify, it does nothing.
func Send(state string) error {
	addr := os.Getenv("NOTIFY_SOCKET")
	if addr == "" {
		return nil
	}
	if strings.HasPrefix(addr, "@") {
		addr = "\x00" + addr[1:] // abstract socket
	}
	conn, err := net.DialUnix("unixgram", nil, &net.UnixAddr{Name: addr, Net: "unixgram"})
	if err != nil {
		return err
	}
	defer conn.Close()
	_, err = conn.Write([]byte(state))
	return err
}

// WatchdogInterval is how often to send WATCHDOG=1: half of $WATCHDOG_USEC,
// or 0 when systemd expects no keep-alives from this process.
func WatchdogInterval() time.Duration {
	if pid := os.Getenv("WATCHDOG_PID"); pid != "" && pid != strconv.Itoa(os.Getpid()) {
		return 0
	}
	usec, err := strconv.ParseInt(os.Getenv("WATCHDOG_USEC"), 10, 64)
	if err != nil || usec <= 0 {
		return 0
	}
	return time.Duration(usec) * time.Microsecond / 2
}
```

```go
// Package daemon is the long-running core. One goroutine, the core loop,
// owns all state: it schedules checks, runs results through the policy,
// persists, and hands alerts to per-notifier delivery. Checks and deliveries
// run in goroutines of their own and report back over channels.
package daemon

import (
	"context"
	"fmt"
	"io"
	"log/slog"
	"math/rand/v2"
	"net/http"
	"os"
	"strings"
	"time"

	"github.com/zezav-cz/alerts/internal/alert"
	"github.com/zezav-cz/alerts/internal/check"
	"github.com/zezav-cz/alerts/internal/config"
	"github.com/zezav-cz/alerts/internal/notify"
	"github.com/zezav-cz/alerts/internal/policy"
	"github.com/zezav-cz/alerts/internal/state"
)

const (
	tickEvery     = time.Second      // resolution of all scheduling
	startSpread   = 10 * time.Second // first runs are spread over this window
	maxQueueAge   = 24 * time.Hour   // undelivered alerts older than this are dropped
	backoffMin    = 10 * time.Second
	backoffMax    = 10 * time.Minute
	maxWait       = time.Hour // longest retry wait, even if a channel asks for more
	shutdownGrace = 10 * time.Second
)

// Options are the daemon's dependencies. Zero values select the real thing;
// tests replace them.
type Options struct {
	Logger     *slog.Logger
	Now        func() time.Time
	Jitter     func(max time.Duration) time.Duration // uniform in [0, max) by default
	Checkers   map[string]check.Checker              // by check name; default built from config
	Notifiers  map[string]notify.Notifier            // by notifier name; default built from config
	HTTPClient *http.Client
	SdNotify   func(state string) error // nil: not run under systemd
	Watchdog   time.Duration            // how often to send WATCHDOG=1; 0 disables
}

// Daemon is the running core. Build it with New, start it with Run.
type Daemon struct {
	cfg      *config.Config
	log      *slog.Logger
	now      func() time.Time
	client   *http.Client
	sdNotify func(string) error
	watchdog time.Duration

	checks    map[string]config.Check
	checkers  map[string]check.Checker
	notifiers map[string]notify.Notifier
	timeouts  map[string]time.Duration

	st       *state.State
	dirty    bool
	next     map[string]time.Time // next run per check
	running  map[string]bool      // check in flight
	sending  map[string]bool      // notifier in flight
	inflight int
	results  chan checkDone
	outcomes chan sendDone
	work     context.Context // canceled only after the shutdown grace
	stopWork context.CancelFunc

	heartbeatURL string
	lastWatchdog time.Time
}

type checkDone struct {
	name string
	res  check.Result
}

type sendDone struct {
	notifier string
	err      error
}

// New builds the daemon: checkers and notifiers from the config, state from
// disk. It fails on anything that would stop alerts from being delivered,
// such as an unreadable token or heartbeat file.
func New(cfg *config.Config, opts Options) (*Daemon, error) {
	d := &Daemon{
		cfg:       cfg,
		log:       opts.Logger,
		now:       opts.Now,
		client:    opts.HTTPClient,
		sdNotify:  opts.SdNotify,
		watchdog:  opts.Watchdog,
		checks:    map[string]config.Check{},
		checkers:  map[string]check.Checker{},
		notifiers: map[string]notify.Notifier{},
		timeouts:  map[string]time.Duration{},
		next:      map[string]time.Time{},
		running:   map[string]bool{},
		sending:   map[string]bool{},
		results:   make(chan checkDone, len(cfg.Checks)),
		outcomes:  make(chan sendDone, len(cfg.Notifiers)),
	}
	if d.log == nil {
		d.log = slog.New(slog.NewTextHandler(io.Discard, nil))
	}
	if d.now == nil {
		d.now = time.Now
	}
	if d.client == nil {
		d.client = &http.Client{Timeout: 30 * time.Second}
	}
	jitter := opts.Jitter
	if jitter == nil {
		jitter = func(max time.Duration) time.Duration { return rand.N(max) }
	}

	for _, c := range cfg.Checks {
		d.checks[c.Name] = c
		if ch, ok := opts.Checkers[c.Name]; ok {
			d.checkers[c.Name] = ch
		} else {
			d.checkers[c.Name] = check.Exec{Command: c.Command, Timeout: c.Timeout}
		}
	}
	for _, n := range cfg.Notifiers {
		d.timeouts[n.Name] = n.Timeout
		if nt, ok := opts.Notifiers[n.Name]; ok {
			d.notifiers[n.Name] = nt
			continue
		}
		nt, err := notify.Build(n, d.client)
		if err != nil {
			return nil, err
		}
		d.notifiers[n.Name] = nt
	}
	if hb := cfg.Heartbeat; hb != nil {
		b, err := os.ReadFile(hb.URLFile)
		if err != nil {
			return nil, fmt.Errorf("heartbeat: %w", err)
		}
		if d.heartbeatURL = strings.TrimSpace(string(b)); d.heartbeatURL == "" {
			return nil, fmt.Errorf("heartbeat: %s is empty", hb.URLFile)
		}
	}

	st, err := state.Load(cfg.StateFile)
	if err != nil {
		d.log.Error("state file unusable", "err", err)
	}
	d.st = st
	now := d.now()
	for name := range st.Checks {
		if _, ok := d.checks[name]; !ok {
			delete(st.Checks, name)
		}
	}
	for name, q := range st.Queues {
		if _, ok := d.notifiers[name]; !ok {
			d.log.Warn("dropping the queue of a removed notifier", "notifier", name, "alerts", len(q))
			delete(st.Queues, name)
		}
	}
	for _, c := range cfg.Checks {
		if _, ok := st.Checks[c.Name]; !ok {
			st.Checks[c.Name] = policy.Initial(now)
		}
		d.next[c.Name] = now.Add(jitter(startSpread))
	}
	// Writing once now turns a missing or read-only state directory into a
	// start-up failure instead of an error logged every second.
	if err := state.Save(cfg.StateFile, st); err != nil {
		return nil, fmt.Errorf("state file not writable: %w", err)
	}
	d.work, d.stopWork = context.WithCancel(context.Background())
	return d, nil
}

// Run is the core loop. It returns after ctx is canceled and in-flight work
// has finished or the shutdown grace has passed.
func (d *Daemon) Run(ctx context.Context) error {
	d.notify("READY=1")
	ticker := time.NewTicker(tickEvery)
	defer ticker.Stop()
	d.tick(d.now())
	for {
		select {
		case <-ctx.Done():
			return d.shutdown()
		case <-ticker.C:
			d.tick(d.now())
		case r := <-d.results:
			d.handleResult(r)
		case o := <-d.outcomes:
			d.handleOutcome(o)
		}
	}
}

// tick starts whatever is due at now.
func (d *Daemon) tick(now time.Time) {
	for _, c := range d.cfg.Checks {
		if !d.running[c.Name] && !now.Before(d.next[c.Name]) {
			d.startCheck(c.Name)
		}
	}
	for _, n := range d.cfg.Notifiers {
		d.dispatch(n.Name, now)
	}
	d.heartbeat(now)
	if d.watchdog > 0 && now.Sub(d.lastWatchdog) >= d.watchdog {
		d.notify("WATCHDOG=1")
		d.lastWatchdog = now
	}
	d.persist()
}

func (d *Daemon) startCheck(name string) {
	d.running[name] = true
	d.inflight++
	checker := d.checkers[name]
	go func() { d.results <- checkDone{name: name, res: checker.Check(d.work)} }()
}

func (d *Daemon) handleResult(r checkDone) {
	d.inflight--
	d.running[r.name] = false
	now := d.now()
	c := d.checks[r.name]
	prev := d.st.Checks[r.name]
	next, a := policy.Evaluate(d.cfg.Host, c.Name, prev, r.res, now, policy.Settings{Confirm: c.Confirm, Repeat: c.Repeat})
	d.st.Checks[c.Name] = next
	d.log.Debug("check finished", "check", c.Name, "state", r.res.State, "output", r.res.Output,
		"duration", r.res.Duration, "confirmed", next.Confirmed, "pending", next.Pending)
	// Output-only changes are not worth a disk write; they ride along with the next one.
	if a != nil || next.Pending != prev.Pending || next.Confirmed != prev.Confirmed {
		d.dirty = true
	}
	if a != nil {
		d.enqueue(*a, now)
	}
	if next.Pending > 0 {
		d.next[c.Name] = now.Add(c.RetryInterval)
	} else {
		d.next[c.Name] = now.Add(c.Interval)
	}
	d.persist()
}

func (d *Daemon) enqueue(a alert.Alert, now time.Time) {
	targets := notify.Route(d.cfg.Routes, a)
	d.log.Info("alert", "kind", a.Kind, "check", a.Check, "state", a.State, "previous", a.PreviousState, "notifiers", targets)
	if len(targets) == 0 {
		d.log.Error("alert matches no route", "check", a.Check, "state", a.RouteState())
	}
	for _, n := range targets {
		d.st.Queues[n] = append(d.st.Queues[n], state.Queued{Alert: a, Enqueued: now, NextTry: now})
	}
	d.dirty = true
}

// dispatch drops expired alerts from a notifier's queue and starts
// delivering its head when that is due.
func (d *Daemon) dispatch(name string, now time.Time) {
	if d.sending[name] {
		return
	}
	q := d.st.Queues[name]
	for len(q) > 0 && now.Sub(q[0].Enqueued) >= maxQueueAge {
		d.log.Error("dropping an undelivered alert", "notifier", name, "check", q[0].Alert.Check,
			"kind", q[0].Alert.Kind, "attempts", q[0].Attempts)
		q = q[1:]
		d.dirty = true
	}
	d.setQueue(name, q)
	if len(q) == 0 {
		return
	}
	// A retry further out than any wait we set means the wall clock stepped
	// back since (rpi01 has no RTC): retry now rather than stall.
	if q[0].NextTry.After(now.Add(maxWait)) {
		q[0].NextTry = now
	}
	if now.Before(q[0].NextTry) {
		return
	}
	d.sending[name] = true
	d.inflight++
	n, a, timeout := d.notifiers[name], q[0].Alert, d.timeouts[name]
	go func() {
		ctx, cancel := context.WithTimeout(d.work, timeout)
		defer cancel()
		d.outcomes <- sendDone{notifier: name, err: n.Send(ctx, a)}
	}()
}

func (d *Daemon) handleOutcome(o sendDone) {
	d.inflight--
	d.sending[o.notifier] = false
	q := d.st.Queues[o.notifier]
	if len(q) == 0 {
		return
	}
	head := &q[0]
	if o.err == nil {
		if head.Attempts > 0 {
			d.log.Info("delivered after retrying", "notifier", o.notifier, "check", head.Alert.Check, "attempts", head.Attempts+1)
		}
		d.setQueue(o.notifier, q[1:])
	} else {
		head.Attempts++
		wait := backoff(head.Attempts)
		if ra := notify.RetryAfter(o.err); ra > wait {
			wait = min(ra, maxWait)
		}
		head.NextTry = d.now().Add(wait)
		d.log.Warn("delivery failed", "notifier", o.notifier, "check", head.Alert.Check,
			"attempt", head.Attempts, "retry_in", wait, "err", o.err)
	}
	d.dirty = true
	d.persist()
}

func (d *Daemon) setQueue(name string, q []state.Queued) {
	if len(q) == 0 {
		delete(d.st.Queues, name)
	} else {
		d.st.Queues[name] = q
	}
}

// backoff is 10s after the first failure, doubling, capped at 10 minutes.
func backoff(attempts int) time.Duration {
	wait := backoffMin
	for i := 1; i < attempts && wait < backoffMax; i++ {
		wait *= 2
	}
	return min(wait, backoffMax)
}

func (d *Daemon) persist() {
	if !d.dirty {
		return
	}
	if err := state.Save(d.cfg.StateFile, d.st); err != nil {
		d.log.Error("saving state", "err", err) // still dirty, so retried next tick
		return
	}
	d.dirty = false
}

func (d *Daemon) shutdown() error {
	d.notify("STOPPING=1")
	d.log.Info("shutting down", "in_flight", d.inflight)
	grace := time.After(shutdownGrace)
	for d.inflight > 0 {
		select {
		case r := <-d.results:
			d.handleResult(r)
		case o := <-d.outcomes:
			d.handleOutcome(o)
		case <-grace:
			d.log.Warn("abandoning in-flight work", "count", d.inflight)
			d.inflight = 0
		}
	}
	d.stopWork()
	d.dirty = true
	d.persist()
	return nil
}

func (d *Daemon) notify(s string) {
	if d.sdNotify == nil {
		return
	}
	if err := d.sdNotify(s); err != nil {
		d.log.Warn("sd_notify failed", "state", s, "err", err)
	}
}
```

```go
package daemon

import (
	"context"

// heartbeat pings the dead man's switch when due. If a notifier has had an
// alert undelivered for longer than fail_after it pings <url>/fail instead,
// so a broken channel is reported by the switch's own alerting.
func (d *Daemon) heartbeat(now time.Time) {
	hb := d.cfg.Heartbeat
	if hb == nil || now.Before(d.nextBeat) {
		return
	}
	d.nextBeat = now.Add(hb.Every)

	url, body := d.heartbeatURL, ""
	if name, age := d.oldestUndelivered(now); age > hb.FailAfter {
		url += "/fail"
		body = fmt.Sprintf("notifier %s has had an alert undelivered for %s", name, alert.Duration(age))
		d.log.Warn("reporting failure to the heartbeat", "notifier", name, "undelivered_for", age)
	}
	go func() {
		ctx, cancel := context.WithTimeout(d.work, 10*time.Second)
		defer cancel()
		if err := ping(ctx, d.client, url, body); err != nil {
			// The URL is a secret: anyone holding it can report this host healthy.
			d.log.Warn("heartbeat failed", "err", strings.ReplaceAll(err.Error(), d.heartbeatURL, "<heartbeat-url>"))
		}
	}()
}

// oldestUndelivered returns the notifier whose queue head has waited longest,
// and for how long.
func (d *Daemon) oldestUndelivered(now time.Time) (string, time.Duration) {
	var name string
	var age time.Duration
	for _, n := range slices.Sorted(maps.Keys(d.st.Queues)) {
		if q := d.st.Queues[n]; len(q) > 0 && now.Sub(q[0].Enqueued) > age {
			name, age = n, now.Sub(q[0].Enqueued)
		}
	}
	return name, age
}

func ping(ctx context.Context, client *http.Client, url, body string) error {
	req, err := http.NewRequestWithContext(ctx, http.MethodPost, url, strings.NewReader(body))
	if err != nil {
		return err
	}
	req.Header.Set("Content-Type", "text/plain; charset=utf-8")
	resp, err := client.Do(req)
	if err != nil {
		return err
	}
	defer resp.Body.Close()
	_, _ = io.Copy(io.Discard, io.LimitReader(resp.Body, 4096))
	if resp.StatusCode/100 != 2 {
		return fmt.Errorf("HTTP %d", resp.StatusCode)
	}
	return nil
}
```

```go
// runCheck runs one check and reports what the policy would do with the
// result, without writing state or sending anything.
func runCheck(cfg *config.Config, name string, stdout, stderr io.Writer) int {
	i := slices.IndexFunc(cfg.Checks, func(c config.Check) bool { return c.Name == name })
	if i < 0 {
		fmt.Fprintf(stderr, "alerts: no check named %q\n", name)
		return 1
	}
	c := cfg.Checks[i]
	res := check.Exec{Command: c.Command, Timeout: c.Timeout}.Check(context.Background())
	fmt.Fprintf(stdout, "%s: %s (%s)\n", res.State, res.Output, res.Duration.Round(time.Millisecond))

	st, err := state.Read(cfg.StateFile)
	if err != nil {
		fmt.Fprintf(stderr, "alerts: state unreadable, assuming a fresh start: %v\n", err)
		st = state.New()
	}
	now := time.Now()
	prev, ok := st.Checks[name]
	if !ok {
		prev = policy.Initial(now)
	}
	next, a := policy.Evaluate(cfg.Host, name, prev, res, now, policy.Settings{Confirm: c.Confirm, Repeat: c.Repeat})
	switch {
	case a != nil:
		fmt.Fprintf(stdout, "policy: would send a %s to %s:\n%s\n", a.Kind, strings.Join(notify.Route(cfg.Routes, *a), ", "), a.Text)
	case next.Pending > 0:
		fmt.Fprintf(stdout, "policy: confirmed %s, %s pending %d/%d, no alert yet\n", next.Confirmed, next.PendingState, next.Pending, c.Confirm)
	default:
		fmt.Fprintf(stdout, "policy: confirmed %s, no alert\n", next.Confirmed)
	}
	return 0
}

		fmt.Fprintf(stderr, "alerts: no notifier named %q\n", name)
		return 1

	defer cancel()

	}

func runDaemon(cfg *config.Config, debug bool, stderr io.Writer) int {
	level := slog.LevelInfo
	if debug {
		level = slog.LevelDebug
	}
	// No timestamps: journald adds its own.
	log := slog.New(slog.NewTextHandler(stderr, &slog.HandlerOptions{
		Level: level,
		ReplaceAttr: func(groups []string, a slog.Attr) slog.Attr {
			if len(groups) == 0 && a.Key == slog.TimeKey {
				return slog.Attr{}
			}
			return a
		},
	}))
	d, err := daemon.New(cfg, daemon.Options{
		Logger:   log,
		SdNotify: sdnotify.Send,
		Watchdog: sdnotify.WatchdogInterval(),
	})
	if err != nil {
		log.Error("cannot start", "err", err)
		return 1
	}
	ctx, stop := signal.NotifyContext(context.Background(), syscall.SIGTERM, os.Interrupt)
	defer stop()
	log.Info("started", "version", version, "host", cfg.Host, "checks", len(cfg.Checks), "notifiers", len(cfg.Notifiers))
	if err := d.Run(ctx); err != nil {
		log.Error("stopped", "err", err)
		return 1
	}
	return 0
}
```

````markdown
# Architecture

`alerts` turns check results into delivered alerts. It has three layers, each behind a small interface, and one goroutine that owns all state.

```
checks ──► result ──► policy ──► alert ──► routing ──► notifier queues ──► notifiers
```

## Layers

**Checks** (`internal/check`) produce a `Result`: a `State` (OK, WARNING, CRITICAL, UNKNOWN — numbered like plugin exit codes), one line of output and a duration. `Checker` is the interface; `Exec` is the only implementation and runs any command that follows the monitoring-plugins convention, so the monitoring-plugins collection and Zezav's own scripts look identical. Built-in Go checks can be added later behind the same interface. `internal/proc` runs the command: no shell, a minimal environment, its own process group, and a timeout that kills the whole group.

**Policy** (`internal/policy`) is a pure function, `Evaluate(previous state, result, now, settings) -> (new state, alert or nil)`. A check's confirmed state changes only after `confirm` consecutive results that differ from it, in both directions, so a flapping check is quiet and a recovery is as trustworthy as a problem. A confirmed change into a non-OK state is a `problem` alert, back to OK a `recovery`; while a problem persists and results agree with it, a `reminder` goes out every `repeat`. Because nothing in the policy touches the clock or the disk, all of that is tested with plain tables.

**Notifiers** (`internal/notify`) deliver an `Alert`. `Telegram` posts the alert's ready-made text to the Bot API; `Exec` hands the alert as JSON on stdin to any command, which is how a new channel is added without a rebuild. `Route` picks the notifiers for an alert: the union of every matching route. A recovery is routed by the state it recovered from, so it reaches whoever got the problem.

## The core loop

`internal/daemon` is the only stateful part. One goroutine runs `Run`, and only it reads or writes the state:

- a ticker (1 s) starts every check whose next run is due, each in its own goroutine, and never the same check twice at once;
- a finished check comes back on the `results` channel; the loop runs it through the policy, persists if something that matters changed, enqueues any alert, and schedules the next run — at `retry_interval` while a change is being confirmed, at `interval` otherwise;
- each notifier has a FIFO queue; the loop sends its head in a goroutine, and the outcome comes back on the `outcomes` channel. Success pops the head; failure schedules a retry with backoff (10 s doubling to 10 min, or Telegram's `retry_after`). Order within a notifier is preserved, so a recovery never overtakes its problem. Alerts older than 24 h are dropped with an error;
- the heartbeat pings an external dead man's switch every `every`, or `<url>/fail` when some notifier has had an alert undelivered for longer than `fail_after` — so a dead host, a wedged daemon and a broken channel are all reported from outside;
- under systemd, `READY=1` after start-up, `WATCHDOG=1` from the loop, `STOPPING=1` on shutdown, so a wedged loop is restarted.

Tests drive the loop's handlers directly with a fake clock instead of running `Run`, which is why `tick`, `handleResult` and `handleOutcome` are separate methods.

## State

`internal/state` keeps each check's policy state and every queue in one JSON file, written atomically (temporary file, fsync, rename) and only when something other than the output text changed, which spares the Raspberry Pi's SD card. A file that cannot be read is moved aside to `state.json.corrupt` and the daemon starts empty: the worst case is a repeated alert, never silence. Checks and notifiers no longer in the config are pruned at start-up.

## Configuration

`internal/config` decodes YAML strictly (unknown keys are errors), fills in defaults, and validates everything it can without touching the system, reporting all problems at once. It refuses any configuration in which some check's WARNING, CRITICAL or UNKNOWN alert would match no route. Puppet renders the file from Hiera and runs `alerts validate` on it before installing it; the daemon additionally checks at start-up that the token and heartbeat files it names are readable.
````

````markdown
# Operations

## Installing

`repo/bolt` installs `alerts` on each host; this is what it has to provide.

- The binary from the GitHub Release matching the host (`alerts_linux_amd64` or `alerts_linux_arm64`), verified against `SHA256SUMS`, at `/usr/local/bin/alerts`.
- A system user and group `alerts`. On the Raspberry Pi add it to the `video` group, so `vcgencmd` works for the throttling check. A check that ever needs root gets a narrow sudoers rule, not root for the daemon.
- `/etc/alerts/config.yaml`, mode 0644, written with `validate_cmd => '/usr/local/bin/alerts --config % validate'`.
- Secret files, mode 0640 `root:alerts`: `/etc/alerts/telegram-token` (the bot token alone) and `/etc/alerts/heartbeat-url` (the healthchecks.io ping URL alone).
- The unit below, and the service enabled and running; restart it when the binary or the config changes.

```ini

Description=alerts: check runner and alert delivery
Wants=network-online.target
After=network-online.target

[Service]
Type=notify
ExecStart=/usr/local/bin/alerts --config /etc/alerts/config.yaml daemon
Restart=always
RestartSec=10
WatchdogSec=60
User=alerts

StateDirectory=alerts

## Configuration reference

```yaml
host: z01                     # optional; default: the short hostname
state_file: /var/lib/alerts/state.json   # optional; this is the default

defaults:                     # all optional; these are the built-in values
  interval: 1m                # between runs while the state is settled
  retry_interval: 30s         # between runs while a change is being confirmed
  timeout: 30s                # per run; then the process group is killed, UNKNOWN
  confirm: 3                  # consecutive differing results before the state changes
  repeat: 6h                  # reminder period while not OK; 0 disables

heartbeat:                    # optional dead man's switch
  url_file: /etc/alerts/heartbeat-url
  every: 5m                   # default 5m
  fail_after: 15m             # default 15m; an alert undelivered this long turns the ping into /fail

notifiers:
  - name: telegram            # [a-z0-9][a-z0-9_-]*, unique
    type: telegram
    token_file: /etc/alerts/telegram-token
    chat_id: "-100123456"     # must be quoted
    timeout: 30s              # optional, default 30s
  - name: ntfy
    type: exec
    command: [/usr/local/libexec/alerts/notify-ntfy]
    env: {NTFY_TOPIC_FILE: /etc/alerts/ntfy-topic}   # optional

routes:                       # an alert goes to every matching route's notifiers
  - notify: [telegram]        # no matchers: matches everything
  - states: [CRITICAL]        # WARNING, CRITICAL, UNKNOWN
    checks: [disk]            # check names
    notify: [ntfy]

checks:
  - name: disk                # [a-z0-9][a-z0-9_-]*, unique
    command: [/usr/lib/nagios/plugins/check_disk, -w, 15%, -c, 10%, -p, /]
    interval: 5m              # any key from defaults can be overridden here
```

Durations are Go durations (`30s`, `5m`, `6h`). Every check must be routable in each of WARNING, CRITICAL and UNKNOWN, or the config is rejected. Commands run without a shell, with `PATH=/usr/local/sbin:/usr/local/bin:/usr/sbin:/usr/bin:/sbin:/bin` and `LANG=C` only.

## Writing a check

Any executable works if it prints one line and exits 0 (OK), 1 (WARNING), 2 (CRITICAL) or 3 (UNKNOWN). Text after the first `|` is performance data and is dropped. Another exit code, a crash or a timeout is UNKNOWN, which alerts too. Try it as the daemon would run it:

```sh
sudo -u alerts env -i PATH=/usr/local/sbin:/usr/local/bin:/usr/sbin:/usr/bin:/sbin:/bin LANG=C /path/to/check; echo $?
sudo -u alerts alerts run <check-name>
```

## Exec notifier contract

The command gets the alert as one JSON object on stdin, then stdin is closed. Exit 0 within `timeout` means delivered; anything else is retried with backoff (10 s doubling to 10 min) for up to 24 h. The first line of stderr is logged.

| Field | Meaning |
|---|---|
| `kind` | `problem`, `recovery`, `reminder` or `test` |
| `host` | `host` from the config |
| `check` | Check name (`test` for a test alert) |
| `state` | New state; `OK` for a recovery |
| `previous_state` | Confirmed state before the change; equal to `state` for a reminder |
| `output` | Output line of the result that triggered the alert |
| `since` | When the current state began (RFC 3339) |
| `time` | When the alert was emitted (RFC 3339) |
| `text` | Ready-made message, e.g. `🔴 z01 disk CRITICAL\nDISK CRITICAL - free space: / 4%` |

A notifier that only wants to send something sends `text`.

## Runbook

**Is it running?** `systemctl status alerts`; logs with `journalctl -u alerts`. Every alert is logged at info level (`msg=alert kind=problem check=disk ...`), every failed delivery at warning.

**See every check result.** Add `--debug` to `ExecStart` (a drop-in), or run one check by hand with `sudo -u alerts alerts --config /etc/alerts/config.yaml run <check>` — it prints the result and what the policy would do, and changes nothing.

**Does Telegram work?** `sudo -u alerts alerts --config /etc/alerts/config.yaml test-notify telegram`. It sends once, without retries, and exits non-zero with the error if delivery failed.

**healthchecks.io says the check is down.** The host, the daemon or its network is gone; `systemctl status alerts` on the host. If it reports a failure (`/fail`) instead, a notifier has been failing for over 15 minutes: the ping body names it, and `journalctl -u alerts | grep 'delivery failed'` shows why. Undelivered alerts stay queued and go out once the channel works again.

**`state file unusable` in the log.** The state was unreadable or from an unsupported version; it was moved to `/var/lib/alerts/state.json.corrupt` and the daemon started fresh. Existing problems alert again once confirmed. Inspect or delete the `.corrupt` file.

**Silencing a check for maintenance.** Not supported in v1: remove the check from Hiera and apply, or let it alert.

## Releasing a new version

Tag `vX.Y.Z` on `main` and push the tag; the release workflow does the rest. Then update the version and both checksums in `repo/bolt`'s Hiera and apply.
````

````markdown
# 001: A separate Go daemon over Netdata for alerting

**Status:** Accepted
**Date:** 2026-10-10

## Context

Zezav's hosts — the server `z01` and the Raspberry Pi `rpi01` — need alerting to Telegram and nothing else. `repo/bolt` ships Netdata for it, which brings a metrics store, a dashboard, an upstream apt repository whose dozen packages have to be pinned together, and several hundred stock alarms tuned for generic servers that have to be silenced one by one. Its stock alarms also miss what actually went wrong on 2026-09-24: nginx was removed by unattended-upgrades and every site was down for eight days with no failing unit to alarm on.

The ready-made checks we want already exist in `monitoring-plugins` (Debian package): small executables printing one line and exiting 0–3. Monit was considered as the runner; it has no ready-made rules either, and its alerting and state handling are less flexible than routing alerts to several channels needs.

## Decision

Write `alerts`, a small Go daemon, in its own repository:

- checks are commands following the monitoring-plugins convention; Zezav-specific checks are scripts kept in `repo/bolt`;
- a long-running daemon with per-check intervals and its state persisted to disk, not a timer-started one-shot;
- a pure policy layer with confirmation, recoveries, reminders and routing;
- notifiers are built in (`telegram`) or any command (`exec`, alert JSON on stdin);
- a YAML config rendered by Puppet from Hiera;
- distributed as statically linked binaries on GitHub Releases, which Puppet downloads with a pinned checksum.

## Consequences

- One small binary per host, no runtime dependencies, nothing listening on the network, no metrics written anywhere.
- We own the code: the policy and delivery logic must be tested well, which the pure policy and the clock-driven daemon tests are designed for.
- The checks are only as good as the plugins and scripts configured; there is no long tail of stock alarms. That is intended — every alert that exists was chosen.
- Netdata comes out of `repo/bolt` once `alerts` is deployed, taking its apt repository and pins with it.
- The repository needs a GitHub remote and a release workflow, which also gives it CI.
````
